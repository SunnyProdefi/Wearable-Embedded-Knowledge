## 1. 两根线背后是电气条件

SCL 是串行时钟线，SDA 是串行数据线。在本课普通开漏模型中，参与者主动拉低或释放，通过合适上拉建立高电平。
上拉电源、总线电容、器件下拉能力与目标时序共同约束边沿，不能只在软件里提高频率。高电平也必须落在两端输入和 I/O 容限允许范围内。
控制器组织 SCL 时序；支持时钟伸展的目标可保持 SCL 为低延缓进展，因此“控制器产生时钟”不代表目标永远不能影响实际边沿。[NXP I2C Rev.7.0](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)

## 2. 一次传输的基本语法

在普通 I2C 语境下：

| 元素 | 基本含义 |
|---|---|
| START，S | SCL 为高时 SDA 从高到低，开始通信 |
| STOP，P | SCL 为高时 SDA 从低到高，结束当前总线占用 |
| Repeated START，Sr | 不先发送 STOP 而重新开始寻址阶段 |
| 地址 + R/W | 选择目标及该消息方向；本课用 7 位目标地址模型 |
| 数据与第九时钟应答 | 每个字节后由接收方给出 ACK 或 NACK |

不要把器件资料里的“包含方向位的地址字节”与软件 API 的目标地址混用。接口究竟接收 7 位、10 位或编码后的值，必须看其契约；不能凭十六进制数的外观判断，也不能无条件左移/右移。

## 3. 为什么读寄存器会先写

假设 Sensor 手册要求“发送内部寄存器编号，再以重复起始读取”，以下是教学事务序列，不是电气波形：

```text
S → 目标地址+W → ACK → 寄存器编号字节 → ACK
  → Sr → 目标地址+R → ACK → ID 数据 → Controller 的末字节 NACK → P
```

编号可占多个字节、ID 也可占多个字节；每个相应字节的应答和读阶段是否继续，要按实际格式展开。若继续读取，Controller 通常对非末字节 ACK；结束读取时的 NACK 可以是正常终止。
写编号不是改写 Chip ID。某些器件要求不同的 STOP/起始组合，不能擅自拆调用。[Linux v6.8 I2C 事务](https://www.kernel.org/doc/html/v6.8/i2c/i2c-protocol.html)

## 4. 按位置解释 ACK/NACK

ACK 表示接收方在相应应答位确认收到该阶段内容，不证明器件身份、写入最终生效或图像输出正常。

| 位置/现象 | 可能含义 | 下一步证据 |
|---|---|---|
| 地址阶段 NACK | 无目标按此地址响应，或目标当前不接受通信 | 总线实例、地址格式、上电/复位/必要时钟 |
| 写数据阶段 NACK | 目标没有接受该字节/阶段 | 访问格式、编号、目标状态、波形位置 |
| 读末字节 Controller NACK | 可能是正常结束读取 | 谁发送、是否末字节、后续 STOP |
| 超时 | 控制器等待条件未满足，不等于必然目标掉电 | 错误状态、SCL/SDA、伸展/仲裁/通知与软件等待 |
| 仲裁丢失或总线忙 | 多发起方/控制器状态等分支 | 平台是否支持该场景、总线归属和失败阶段 |

同一个软件错误码可能经控制器驱动汇总不同硬件原因；先保存可安全读取的状态，再与事务位置关联。不能只凭 “NACK” 一个词判定器件损坏。

## 5. 返回值、数据与恢复分别处理

Linux `i2c_transfer()` 返回执行消息数或负错误码；两个消息的请求应核对返回为 2，再使用返回数据。其他 API 可返回字节数或数据值，不能统一按“0 成功”。[Linux v6.8 I2C API](https://www.kernel.org/doc/html/v6.8/driver-api/i2c.html)
还要检查 ID 解码、范围和预期值；传输失败后的 Buffer 不能默认当作本次有效数据。
Controller 完成中断、总线事务结束、器件接受配置、Camera 帧完成是不同阶段。

恢复需先识别当前所有者及在途事务。不能在另一个控制器或固件仍拥有总线时盲目拉 GPIO、复位器件或发送固定次数时钟；总线恢复能力和步骤按平台/器件协议核对。

## 6. 模拟问题：地址 ACK，但 ID 错误

类型：模拟，无已确认根因。候选包括应答的是另一器件、寄存器编号/长度/顺序错误、读写组合不符、返回长度不足或使用旧 Buffer。
验证按同一请求记录总线路径、目标地址表示、消息内容、应答位置、返回长度和原始 ID 字节，再按手册解释；保留启动条件分支。
如果波形与消息都匹配，再调查目标状态和芯片版本。不能把地址 ACK 直接视为 ID 已正确，也不能把 ID 错误统一归为电源问题。
候选修正依据已证实的地址、格式或结果处理问题选择，不先无限重试。
