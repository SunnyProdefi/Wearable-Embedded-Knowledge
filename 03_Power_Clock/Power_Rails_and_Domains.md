# S2-02：电源轨、电源域与 PMIC/PMU

## 课程信息与目标

- 日期：2026-10-22；前置：[S2-01](Electrical_Basics_and_Regulators.md)、[MMIO](../02_Processor_Memory/Registers_and_MMIO.md)。
- 目标：沿“软件资源 → 稳压/开关控制 → 电源网络 → 用电模块”定位供电条件，避免把名称、域状态与引脚实测混为一谈。
- 通用架构与 Linux v6.8 regulator 示例；未指定电压或域拓扑。集中回答 [本轮清单](../Study_Pack_S1-08_S2.md)，状态见 [Progress](../Progress.md)。

## 1. 四个名字分别描述什么

| 名称 | 含义 | 不能只凭名称推定什么 |
|---|---|---|
| Power Rail，电源轨 | 一路供电网络 | 不保证只有一个负载或一个可独立关断域 |
| Power Domain，电源域 | 具有某种共同电源管理边界的电路集合 | 不必与板上一条电源轨一一对应 |
| PMIC，电源管理集成电路 | 可集成稳压、开关、监测和时序等功能的芯片 | 不保证每颗都包含相同功能 |
| PMU，电源管理单元 | 电源管理功能模块，可在 SoC 内或其他位置 | 不保证是独立芯片，也不能仅凭缩写判定位置 |

一种教学供电关系：电池 → PMIC 稳压输出 → 共用电源网络 → 多个器件；SoC 内部还可能通过电源开关形成不同域。这是功能关系，不是指定产品原理图。
Clock Gating 只控制时钟活动；Power Gating 控制指定电路供电，二者不是同一动作。

## 2. Camera 电源命名只提供线索

| 常见名称 | 常见用途 | 实际必须查 |
|---|---|---|
| AVDD | 模拟部分供电 | 允许范围、噪声要求、时序与对应引脚 |
| DVDD | 数字核心供电 | 是否由片内稳压产生、外部供电要求及状态 |
| DOVDD / VDDIO | I/O 相关供电 | 输入输出电平、上拉电源、容限与掉电行为 |

这些是常见命名，不是通用固定电压表。DOVDD 与 VDDIO 是否同一网络、内部是否还有子域，都以目标器件和原理图为准。
控制接口可通信，只能支持当前访问所需部分成立，不能由此证明模拟采集、数据输出等全部资源正常。

## 3. 三种“开着”需要分别取证

| 状态 | 从哪里知道 | 仍可能缺什么 |
|---|---|---|
| 驱动认为已请求电源 | 调用路径、引用和返回值 | 资源绑定是否正确，是否真的控制预期网络 |
| 稳压器配置/状态为启用 | 按接口读取的配置或状态 | 输出是否达到目标、负载端是否掉压 |
| 负载端实际有合格供电 | 对应引脚处的静态/动态测量 | 复位、时钟、内部状态和接口条件 |

Linux regulator consumer 接口按设备供电资源匹配 provider，并管理共享使用。某消费者 disable 不保证物理输出立即关闭，因为其他消费者仍可能持有启用引用。[Linux v6.8 regulator](https://www.kernel.org/doc/html/v6.8/power/regulator/consumer.html)
软件配置值不是实测电压；也不能通过强制关闭共享电源来验证本设备状态，而忽略其他使用者。

## 4. 电源域切换涉及什么

某些域关闭后寄存器和 SRAM 内容丢失，某些设计有保留区域；隔离、复位、时钟、互联访问和恢复过程需要由平台协调。
“状态保留”须说明保留对象、供电条件和低功耗状态，不能把 Retention 等同于整域完全掉电后仍保存全部内容。
AP、MCU 和设备可能处于不同域。AON 表示在指定状态下保持的资源集合，不自动包括 CSI、DDR 或整个 Camera 通路。
本课只建立边界，不给出通用关域寄存器流程；软件框架中的域依赖必须匹配硬件。

## 5. 模拟问题：disable 后电源仍有电

类型：模拟，无实测结论。可能为共享引用、控制资源映射错误、独立供电路径、未放电或从 I/O 路径反向供电等不同情况。

| 验证动作 | 所需证据 |
|---|---|
| 检查调用与共享使用 | 谁持有资源、是否执行了匹配的释放、实际 provider 是谁 |
| 检查真实控制路径 | 稳压器/负载开关使能及板级连接 |
| 测量负载端及关联 I/O | 关闭前后时间线、放电过程及其他供电路径 |

先区分“框架没有要求关”“开关未关”“已经关但测点仍有电”。未取得证据时不宣布漏电或 PMIC 损坏。
候选处理包括修正资源映射和引用、按器件要求管理 I/O 与掉电顺序；不是忽略共享关系强行关电。
